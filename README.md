# Hi, I'm Nandha

I build **[Ember](https://ember.mov)**, a journal that remembers your people.
It runs on iPhone, iPad and Mac, and I'm the only developer.

- Native SwiftUI and SwiftData, with my own iCloud sync built on CKSyncEngine
- No AI. Your entries stay on your devices and in your own iCloud
- Available in 12 languages
- [App Store](https://apps.apple.com/app/id6775558241) · [Feedback board](https://feedback.ember.mov)

Ember's code is private, so most of my commits show up as private contributions.
